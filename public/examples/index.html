Codeblocks examples

Runnable editors, clangd-backed read-only snippets, Compiler Explorer output views, and consumer-rendered results.

Runnable with reader-editable options

The compact compiler bar discovers Compiler Explorer languages and compiler display names. Execution arguments and stdin stay together in its execution panel; the output tabs select the result view.

#include <iostream> int main(int argc, char** argv) { std::string input; std::getline(std::cin, input); std::cout << argc << ": " << argv[1] << " / " << input << '\n'; } #include <print> int main() { std::println("A second source tab"); }

Live assembly beside the source

This block compiles 600 ms after edits without executing the program. It can display assembly, compiler diagnostics, or a requested Compiler Explorer tool result.

int square(int value) { return value * value; }

Live execution output

Editing this program recompiles and executes it after 600 ms. Replay and Compiler Explorer actions live in the output pane instead of a separate toolbar.

#include <cstdio> int main() { std::puts("Live execution"); }

Read-only

Read-only is an author option, not a reader-facing toggle. UI parts can be hidden independently.

#include <array> constexpr std::array values{1, 2, 3};

Inline highlighting with clangd

The wrapper is transparent, follows the page theme, and stays in this sentence: constexpr int answer = 42; It becomes a clangd-backed Monaco surface once the shared runtime is ready.

Simple editors

simple keeps the syntax-only fallback permanently: Monaco and clangd are never loaded for these blocks. Python is also available in this mode.

constexpr int simple_only = 42; def greet(name: str) -> str: return f"Hello, {name}!"
